# 📖 Project Overview

Artificial Intelligence is transforming modern education by improving learning experiences, classroom efficiency, and institutional decision-making.

This project explores **Global AI Adoption in Education** through interactive dashboards developed in **Tableau Desktop**. The dashboards provide meaningful insights into AI adoption trends, regional comparisons, student and teacher usage, urban-rural disparities, and the most widely used AI platforms.

To improve accessibility, the Tableau dashboards are embedded into a simple Flask web application.

---

# 🎯 Objectives

- Analyze AI adoption across different countries and regions.
- Compare AI usage between students and teachers.
- Identify the most popular AI platforms.
- Analyze Urban vs Rural AI adoption.
- Build interactive Tableau dashboards.
- Present insights using Tableau Story.
- Integrate Tableau Public dashboards into a Flask web application.

# 📈 Key Insights

- AI adoption has consistently increased over the years.
- Urban regions demonstrate higher AI usage than rural areas.
- Students generally use AI tools more frequently than teachers.
- Internet penetration strongly influences AI adoption.
- Different regions exhibit varying AI implementation levels.
- Interactive dashboards simplify comparative analysis.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/SameerKumar751/global-ai-adoption-analysis.git
```

Go inside the project

```bash
cd global-ai-adoption-analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
